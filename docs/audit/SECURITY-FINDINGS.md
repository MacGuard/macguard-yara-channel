# Security and correctness findings

Severity: CRITICAL / HIGH / MEDIUM / LOW. "Fixed" means: reproduced, regression test added, fix applied, test green (and red on the old code where noted). "Deployed" is stated separately because a fix in the repository protects nobody until it is published.
Raw sub-audits (read-only agents) are kept in `evidence/audit-quarantine-service.md` and `evidence/audit-public-portal.md`; their ids (`H-1`, `M-1`, `W-01` …) are cross-referenced below. Commits: `65e16a4` and `6c0cc5f` (quarantine), `a5956a5` (crypto/inventory/evidence), `b5642b3` (CI), `8c3cf22` (Mermaid + CSP), `6c4f830` (portal), `d787ffd` (verifier).

No CRITICAL finding. One HIGH in the quarantine service (latent: the service is not deployed), one HIGH on the live portal (known-vulnerable Mermaid, no CSP), both fixed in the repository; the portal one is fixed live only after the next deployment (see PRODUCTION-READINESS).
