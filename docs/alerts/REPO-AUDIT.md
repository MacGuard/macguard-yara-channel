# Repository audit before building Subscriptions and Alerts (2026-10-23)

*Resumen: la web actual es estática (GitHub Pages y Cloudflare Pages); no existe backend público, autenticación de usuarios ni base de datos para suscripciones. Lo único dinámico del repositorio es un servicio privado de cuarentena (Cloudflare Worker + D1 + OAuth de GitHub) que no está desplegado y no sirve a usuarios externos. Por eso esta entrega construye un servidor de referencia (Python estándar + SQLite) y lo marca como no desplegado.*

## What this implies for the scope

* P0 (public, static) is real and deployable as files: Explore, Sources, public RSS, committed data reproducible from the repository.
* P1 to P2 (accounts, subscriptions, private feeds, e-mail, webhooks, organisations) need a backend that does not exist as a hosted service. They are implemented and tested as a **reference backend** and are labelled *not deployed*.
* P3 (Cloud correlation) is a contract plus an executable reference matcher; there is no inventory and no service.
